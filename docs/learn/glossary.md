# 用語集

| 用語 | 意味 |
|---|---|
| **VLM(Vision-Language Model)** | 画像と文章の両方を扱える基盤モデル。ここでは、画面を見て次の行動を計画する |
| **基盤モデル(Foundation Model)** | 大規模に学習した汎用のモデル |
| **計画 / 実行の分離** | 考えるのはモデル、動かすのは専用の部品、という設計 |
| **9 つの意図** | `prompts/functions.py` の 9 つの関数(分解・説明・次の行動・経験・変化の要約・統合・コード生成・サブルーチン・停滞の診断) |
| **TODO** | 目標を分解した作業 1 件。`todoId`・`description`・`doneCriteria`(完了を判定する、観測できる条件) |
| **StepLog** | 1 ステップの記録(番号・時刻・TODO・画像の参照・理由・行動・結果の要約) |
| **MainLoop** | 撮る → 行動を選ぶ → 理由 → 実行 → 撮り直す → 変化を要約、を繰り返すループ |
| **Watchdog** | 停滞を見張り、TODO の再構築を起こす。診断(モデル)か、同じ TODO が N ステップ続いたか(強制) |
| **停滞(stall)** | 同じことを繰り返して、進まない状態 |
| **スキル(Skill)** | 保存済みの操作。`procedure`(手順書の文章)か `script`(Python のコード) |
| **procedure スキル** | 手順書。**非強制のガイダンス**として、ループに渡す(従わなくても止めない) |
| **script スキル** | Python のコード。サンドボックスで実行する |
| **API primitive** | 1 回の入力(パッド・キー・マウス・OCR・移動)。`ApiPrimitives` のメソッド |
| **ActionDispatcher** | 行動を、API かスキルへ振り分ける。API は**許可リスト**だけ |
| **許可リスト / ブロックリスト** | 許可するものを列挙(他は拒否)/ 禁止するものを列挙(他は通す)。前者のほうが安全側 |
| **サンドボックス** | 制限した環境でコードを動かす仕組み。ここでは `exec` + 制限した `__builtins__` + 差し替えた `__import__`(ブロックリスト方式で、完全ではない) |
| **HID(Human Interface Device)** | パッド・キーボード・マウスなどの入力デバイス。ここでは仮想入力(ViGEm・SendInput) |
| **ViGEm** | 仮想ゲームパッド(XInput / DS4)を作るドライバ(ViGEmBus)。`vgamepad` パッケージ経由 |
| **SendInput** | Windows のキーボード・マウス入力 API。ctypes で呼ぶ |
| **OCR** | 画像から文字を読む |
| **RAG(検索拡張生成)** | 検索で拾った知識を、モデルの入力に足す仕組み。ここでは **TODO 生成の前だけ**で使う |
| **Experience(経験)** | `extract_experience` が抽出した知見(`title`・`summary`・`problem`・`betterWay`)。RAG の `experience` 名前空間に入れる |
| **ホールドアウト** | スキルの生成に使わなかった、別のシナリオ。受け入れゲートで汎化を確かめる |
| **受け入れゲート** | ホールドアウトのすべてで成功したスキルだけ、登録する |
| **Protocol** | 「この形のメソッドを持っていればよい」という約束(構造的な型付け) |
| **ScriptedFoundationModelClient** | 決まった答えを順に返す、テスト用の偽のモデル |
| **Pydantic** | 型ヒントでデータを検証するライブラリ。モデルの出力を受けて検証する |
| **model_validator** | 全項目がそろった後に、項目どうしの整合を検査する Pydantic の仕組み |
| **`ast`** | Python のソースを構文木にする標準ライブラリ。「このモジュールは、あれを import していない」を、テストで確かめる |
| **監査可能性** | 何をしたか・なぜしたかが、後から追えること。理由が空なら実行しない |
| **HUD** | 実行を、WebSocket でリアルタイムに映す監視画面(開発者向け) |
| **fail-closed** | 設定が壊れたとき、閉じる(起動しない・拒否する) |
| **viewer / operator / admin** | 見る / 実行の開始・停止 / スキル・設定の変更。順位で比べる |
| **CSRF・DNS rebinding** | 別のサイトから、ブラウザ経由でローカルのサービスを操作・読み取りする攻撃。Origin の検査と Host の許可リストで守る |
